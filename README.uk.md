# Драконячий архітектор

![Невелике підземелля в стилі «Ескіз олівцем»](docs/images/header.jpg)

Мапи підземель для настільних рольових ігор, наче намальовані олівцем на папері. Малюєш кімнати й коридори,
ставиш меблі, обираєш стиль — і передаєш мапу на стіл [Owlbear Rodeo](https://www.owlbear.rodeo) разом зі
стінами для динамічного туману або вивантажуєш у PNG чи UVTT.

**[Відкрити редактор](https://gammercvest.github.io/draconic-architect/)** · [English](README.md)

## Можливості

- Підлога прямокутниками, багатокутниками чи пензлем по клітинках; вирізи для колон і ніш; межі кімнат з назвами.
- Кілька стилів: ескіз олівцем, чорнило й крапки, креслення, пергамент з контурами та інші.
  Можна змішувати стилі на одній мапі або зробити свій — з текстурами паперу й підлоги та власними штампами.
- Понад 280 меблів і предметів згори, перемальованих чорнилом стилю мапи.
- Шари, пріоритет, з'єднання, закріплення одного об'єкта на іншому, об'єднання фігур.
- Вивантаження в PNG або UVTT (`.dd2vtt`) для Smoke & Spectre, Foundry та інших.
- Інтерфейс українською та англійською.

## Як додати в Owlbear Rodeo

Додай розширення за посиланням (як саме — у [посібнику](https://extensions.owlbear.rodeo/guide)):

```
https://gammercvest.github.io/draconic-architect/manifest.json
```

У кімнаті відкрий Draconic Architect з меню розширень, намалюй мапу й натисни **На стіл**.
З'явиться нова сцена: мапа як фон і стіни вздовж кожного контуру кімнат.
